# 更新记录

## 1.0.1 — 2026-11-03

- 根据食品主副用途、真实加工工序和每份成本重新平衡持续时间。专一食品保留长效用途，强复合食品的单项能力较短。
- 成品一般采用半分钟或整分钟分档。半加工以同效果成品的3/7为中心，简单条目下浮10%—15%，复杂条目上浮10%，就近5秒。
- 咖啡、加料饮品、甜点及熟鱼片分别比较；复杂成品主要增强主效果。
- 滋养等原有效果同时纳入时长平衡。66项移除、32项明确保留、13项待核保留的选择保持。
- 西瓜冰棍的瞬间治疗Ⅰ触发率由25%提高到50%；蜂蜜曲奇等其他食品概率保持。
- 固定效果组合、等级、营养、容器及21项机制保持。新陈代谢仍使用现有快慢两档。

验证：9项结算检查；Fabric Loader 0.19.5核心及九附属环境各37项GameTest，分别实际食用75种和439种映射食品；九附属与保留的136模组整包测试副本通过客户端提示、HUD及到期恢复检查。测试使用发行版同一份JAR。

升级：客户端和服务器均替换旧JAR，避免两个版本同时存在。已有食品覆盖配置仍优先于新默认值。真实远程多人、长期平衡、滋养与低饥饿回血消耗交互，以及呛鼻全部条件转换尚未全面实测。

Main gameplay Java sources are unchanged. Version 1.0.1 updates fixed food data and metadata; test fixtures check the new values.
